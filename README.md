# Portfolio: Lathifah Sahda

Source code of my personal portfolio site: https://lathifash03.github.io

The site presents my research and projects in NLP, LLM evaluation, and data analysis, with a case study for each one: the problem, the approach, the tools, and the measured result.

## What is on the site

- Projects, including my thesis pipeline, an agentic verification layer over a knowledge graph, topic modeling on Indonesian news, and data analysis work.
- Work and research experience.
- A downloadable CV.
- Content in English and Indonesian.

## Stack

- Next.js with TypeScript
- Content kept in `content/en/` and `content/id/`
- ESLint for linting
- A build check script (`scripts/check-tbd.mjs`) that fails the build when unfinished placeholders are left in published content
- Deployed to GitHub Pages with a workflow in `.github/workflows/`

## Run it locally

```bash
git clone https://github.com/lathifash03/lathifash03.github.io.git
cd lathifash03.github.io
npm install
npm run dev
```

Then open http://localhost:3000. See `package.json` for the other scripts.

## Notes

Some of my work was done in company or team repositories that I cannot make public. The case studies describe what I built and what I measured, without exposing internal code or data.
